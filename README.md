## About

VS-code is a code editor. This repository contains the source code for the project.

## Features

- Syntax highlighting
- Auto-completion / IntelliSense
- File explorer and project navigation
- Search and replace
- Extensions / plugin support
- Debugging support

## Tech stack

- Primary language: TypeScript (99.1% of the codebase)
- Runtime/tools: Node.js, npm (see package.json for exact scripts and requirements)

## Prerequisites

- Node.js (version 14 or later recommended)
- npm or yarn

## Install

1. Clone the repository:

   git clone https://github.com/ITIshu/VS-code.git
   cd VS-code

2. Install dependencies:

   npm install

## Development

- Build (if applicable):

  npm run build

- Start the development server / run the app:

  npm start

- Lint:

  npm run lint

Check package.json for the exact scripts the project provides.

## Testing

Run tests with:

npm test
